Date: 2026-11-11. Checker: a separate Opus agent that did not write the rule. It read the diff, fetched the EPO pages itself, and derived the dates by hand with the system calendar, not with the code. No attorney took part. `reviewedBy` stays `null`.

## Law

| Fact | Source | Result |
|---|---|---|
| The communication sets the period ("within a period to be specified"). | [Rule 71(1) EPC](https://www.epo.org/en/legal/epc/2020/r71.html) | Agrees |
| A period that the EPO specifies is two to four months, in certain circumstances up to six months. | [Rule 132(2) EPC](https://www.epo.org/en/legal/epc/2020/r132.html) | Agrees; range 2 to 6 |
| In practice four months for substantive matters, two months for minor or formal deficiencies, six months only in exceptional cases; at least four months with a Rule 53(3) request. | [Guidelines E-VIII, 1.2](https://www.epo.org/en/legal/guidelines-epc/2026/e_viii_1_2.html) | Agrees; all inside 2 to 6 |
| The communication must state the period; no reply in time gives deemed withdrawal; further processing is available. | [Guidelines C-III, 4.2](https://www.epo.org/en/legal/guidelines-epc/2026/c_iii_4_2.html), [Article 94(4) EPC](https://www.epo.org/en/legal/epc/2020/a94.html) | Agrees |
| An extension on request counts from the start of the original period. | [Guidelines E-VIII, 1.6.1](https://www.epo.org/en/legal/guidelines-epc/2026/e_viii_1_6_1.html) | Out of scope of v1; the README says so |
| Rule 134(1) EPC applies only after the seven-day extension. | [Guidelines E-II, 2.3](https://www.epo.org/en/legal/guidelines-epc/2026/e_ii_2_3.html) | The late-receipt note does this |
| The new Rule 126(2) EPC applies from 1 November 2023. | [Rule 126 EPC](https://www.epo.org/en/legal/epc/2020/r126.html), footnote on CA/D 10/22 | `effectiveFrom` 2023-11-01 agrees |

The checker found no "otherwise provided" case that gives an Art. 94(3) communication a period outside 2 to 6 months, and no period in weeks.
